# 💊 Quick Medicine Info

A full-stack web application designed to help users quickly search, compare, and get detailed information about medicines safely, along with emergency contacts and AI-powered health insights.

---

## 🚀 Tech Stack

### **Frontend**
* **React.js** (with Vite)
* **Tailwind CSS** & **Bootstrap** for styling
* **Lucide React** / Custom icons
* **Axios** for API requests

### **Backend**
* **Python & FastAPI**
* **Uvicorn** (ASGI server)
* **Groq API / AI Integration** for smart medical summaries and diagnostics
* **Environment Variables (`python-dotenv`)** for secure configuration

---

## ✨ Features

* 🔍 **Instant Medicine Search:** Quick lookups for medicine names, uses, dosages, and side effects.
* ⚖️ **Medicine Comparison:** Compare two different medicines side-by-side to understand differences.
* 🤖 **AI-Powered Insights:** Integrated with Groq AI to answer medicine-related queries safely.
* 🚨 **Emergency Contacts:** Quick access to emergency helplines and safety notices.
* ⭐ **Favorites & History:** Save searched medicines and review previous lookups.
* 📱 **Responsive Design:** Fully optimized for both mobile and desktop screens.

---

## ⚙️ Installation & Setup Locally

To run this project on your local machine, follow these steps:

### 1. Clone the Repository
```bash
git clone [https://github.com/ifrahcoder/quick-medicine-info.git](https://github.com/ifrahcoder/quick-medicine-info.git)
cd quick-medicine-info
cd backend
# Create and activate virtual environment
python -m venv venv
# On Windows:
.\venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
GROQ_API_KEY=your_actual_groq_api_key_here
uvicorn app.main:app --reload
cd frontend
# Install dependencies
npm install

# Run development server
npm run dev
